# PixelCraft — 3D-песочница на гексагональных призмах (релиз 3.4)

Воксельная песочница, которая запускается как **полноценное настольное
приложение** на Electron (свой оконный режим, надёжный захват мыши) — и при
этом по-прежнему открывается **прямо в браузере**, в т.ч. в панели просмотра
OpenCode. Внешних файлов ассетов нет: текстуры генерируются процедурно в
canvas, Three.js лежит локально.

## Что нового в релизе 3.4

- **Тело игрока смещено ниже и вперёд.** Торс опущен (верх ≈ 1.20 при глазной
  высоте 1.62) и вынесен вперёд, руки прижаты к корпусу — при взгляде вниз
  видны грудь и ноги, а не «бесконечная грудь» перед глазами.
- **Высокие деревья с толстыми стволами.** Высота рандомизирована: от ~3 ростов
  игрока (6 блоков) до 50. Чем выше дерево — тем толще ствол (гекс-кластер
  радиуса 1–3) и крупнее крона (сглаженный конус из дисков листвы). Высота мира
  поднята до 130, чтобы такие деревья влезали.
- **Окно инвентаря: экипировка + персонаж.** Рядом с гексагоном сот (91 ячейка)
  появился гекс предпросмотра персонажа того же размера, они соприкасаются
  гранью. По свободным граням — **7 слотов экипировки**: шлем, нагрудник,
  штаны, сапоги, перчатки, оружие (правая/левая рука). Любой предмет из
  инвентаря можно «надеть»: кукла в предпросмотре раскрашивается его цветом,
  оружие видно только пока надето. Выберите слот хотбара и кликните по слоту
  экипировки — предмет перейдёт туда (1 шт.), снятый вернётся в инвентарь.

## Что нового в релизе 3.3

- **Частицы «рассыпания».** При разрушении блока из него вылетают фрагменты
  текстуры блока (небольшие спрайты-осколки с гравитацией и затуханием).
- **Инвентарь-соты (грань 6 ячеек, 91 ячейка).** Логика «как в Minecraft»:
  - ломаете блок — он попадает в инвентарь (стаки до 64);
  - ставите блок — тратится один из выбранного слота;
  - `I` открывает сотовое поле, клик по ячейке обменивает её с выбранным
    слотом хотбара.
  - На старте в первых 8 слотах — по стаку каждого блока палитры (64), так что
    строить можно сразу, а счётчики в хотбаре растут/убывают по мере работы.
- **Базовое тело игрока из гекс-призм** (ноги, торс, руки, кисти) — видно
  частично, если наклонить взгляд вниз.
- **Рука (viewmodel) из гекс-призм** в правом нижнем углу: при каждом нажатии
  мыши (или `E`/`Q`) рука делает взмах.

## Что нового в релизе 3.2

- **Настольное приложение (Electron).** Добавлены `package.json` и `main.js`.
  Запуск — `npm start`. Своё окно `PixelCraft`, скрытое меню, `F11` — полный
  экран, `F12` — инструменты разработчика, `Ctrl+R` — перезапуск.
- **Адекватный захват мыши (Pointer Lock).** В приложении разрешение
  `pointerLock` выдаётся автоматически, поэтому при клике мышь захватывается
  «по-настоящему» (как в Minecraft), а не «тянуть зажатой кнопкой».
- **Экран паузы.** `ESC` освобождает мышь и ставит игру на паузу; клик по
  оверлею возвращает захват и продолжает игру. Пока игра на паузе, ввод и
  физика не обрабатываются.
- **Интерфейс переведён на гексагоны** (в едином стиле с блоками мира):
  - слоты хотбара и образцы блоков — шестиугольники;
  - прицел — гексагональный контур;
  - под хотбаром — гекс-табличка с названием выбранного блока;
  - оверлей/меню: гекс-панель, гекс-бейдж, клавиши-«гексы» и кнопка-гекс.

## Что нового в релизе 3.1

- **Исправлено отсечение боковых граней** (главный баг релиза 3). Индексация
  рёбер в `nbCell()` была рассогласована с геометрией `HEX_VERTS`: 4 из 6 рёбер
  проверяли «не того» соседа (отражение по оси Z). Из-за этого боковые грани на
  стыках блоков рисовались **на неверной стороне**, а на их месте появлялись
  «дыры», сквозь которые был виден фон/туман — визуально это выглядело как
  «нетекстурированные грани у блоков, соприкасающихся с другими».
- Общее число граней при этом не менялось (число пар «блок–воздух» инвариантно
  к перестановке рёбер), поэтому баг не ловился простым сравнением количества.
- Добавлена метка версии в углу экрана и cache-busting (`?v=…`) для скриптов.

## Что нового в релизе 3

- **Мир полностью переведён на гексагональные призмы**: блок — шестиугольная
  призма (pointy-top), у каждой ячейки **6 боковых соседей + верх/низ**.
- Решётка мира — **200 × 200 колонок, высота 130** (axial/odd-r раскладка).
- Переписаны под гекс всё, что требовалось: хранение данных, генерация меша
  (верх/низ — шестиугольники, 6 боковых граней на ребро), рейкаст (маршевый),
  коллизия игрока, осыпание листвы и подсветка (контур гекс-призмы).
- Сохранена «основа»: размер, слои земли, текстуры и всё поведение.

## Что уже есть

- Ходьба, бег, прыжки, гравитация и столкновения с блоками.
- Копание (ЛКМ), установка блоков (ПКМ), хотбар и **инвентарь-соты** (`I`).
- **Экипировка**: гекс предпросмотра персонажа рядом с сотами и 7 слотов
  (шлем, нагрудник, штаны, сапоги, перчатки, оружие в обе руки) — клик по
  слоту надевает/снимает выбранный предмет из инвентаря.
- **Разрушение по блокам**: брёвна и листва ломаются по одному срубленному блоку — дерево не исчезает целиком от удара по нижнему бревну.
- **Осыпание листвы**: листва, оставшаяся без опоры (рядом нет брёвен), опадает — как в оригинальном Minecraft. Пока без «физики» падения брёвен.
- **Частицы** при разрушении блоков, базовое **тело игрока** (гекс-призмы) и **взмах руки** на нажатия мыши.
- Подсветка блока под прицелом, HUD (FPS/координаты), режим полёта.

## Слои земли

Сверху вниз: **дёрн → почва → песок → глина → камень**.

- Общая глубина копаемой земли — **50 блоков**; ниже идёт **бедрок**, который нельзя сломать.
- Верхний слой мира и низ — тоже **бедрок**.
- Деревья и кустарники генерируются процедурно; настоящие пиксель-арт текстуры (атлас 4×4, генерируется в рантайме).

## Как запустить

### Как приложение (рекомендуется)

Требуется [Node.js](https://nodejs.org/) (проверено на Node 24).

```bash
npm install     # один раз — скачает Electron
npm start       # запустить приложение
```

Первый `npm install` скачивает Electron (~100 МБ). Дальше запуск мгновенный.

### Как веб-страницу

Откройте `index.html` в браузере (двойной клик или через панель просмотра
OpenCode) и нажмите «Нажмите, чтобы играть». Встроенные панели просмотра могут
запрещать Pointer Lock — тогда обзор работает перетаскиванием зажатой ЛКМ.

Сеть не требуется — `vendor/three.min.js` лежит локально.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение |
| Мышь | обзор (автоматический захват курсора) |
| `ЛКМ` | сломать блок (подбирается в инвентарь) |
| `ПКМ` | поставить блок (тратится из выбранного слота) |
| `1`–`8` / колесо | выбор слота хотбара |
| `I` | открыть/закрыть инвентарь + экипировку |
| `Пробел` | прыжок |
| `Shift` | бег |
| `F` | включить/выключить полёт |
| `E` / `Q` | сломать / поставить блок (если захват мыши недоступен) |
| `ESC` | пауза (освободить мышь) / закрыть инвентарь |
| `F11` / `F12` | полный экран / инструменты разработчика (в приложении) |

> Если окружение не даёт «захватить» мышь (pointer lock), можно осматриваться,
> зажав левую кнопку мыши. Ломать/ставить блоки тогда — клавишами `E` / `Q`.

## Структура

```
main.js             # главный процесс Electron (окно, pointer lock, F11/F12)
package.json        # npm-манифест, зависимости и скрипты

```

## Технические заметки по гекс-миру

- Раскладка **pointy-top**, координаты ячеек — offset (odd-r); соседи и расстояния
  считаются через axial-координаты.
- Индексация рёбер `nbCell(col,row,edge)` согласована с геометрией: ребро `e`
  идёт от вершины `HEX_VERTS[e]` к `HEX_VERTS[e+1]`, его внешняя нормаль — угол
  `60° + 60°·e`; поэтому `0=SE, 1=SW, 2=W, 3=NW, 4=NE, 5=E`.
- Мировой шаг: ширина гекса `√3·R`, шаг рядов `1.5·R`; `R = 1`, высота призмы `1`.
- Верх/низ — гексагональные «крышки», грани рисуются только если сосед пуст.
- Рейкаст — маршевый (шаг 0.1, дальность 6); установка блока — в последнюю
  пустую ячейку перед попаданием.
- Коллизия — по 9 точкам отпечатка игрока (углы/середина рёбер/центр).
